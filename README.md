# Klyvro

Versão pública e estática do Klyvro para GitHub Pages.

## Recursos

- Interface gamer preta, cinza e vermelha.
- Servidores Klyvro Lobby, Competitivo e Minecraft.
- Canais, mensagens, membros, busca global e painéis locais.
- Rascunhos e mensagens salvos no navegador com `localStorage`.
- Modo leve/visual e configurações locais.
- Sem backend, banco de dados, chaves ou dependências externas.

## Publicação

O deploy é feito automaticamente pelo workflow `.github/workflows/pages.yml` usando GitHub Pages.
